# Linux Department Access Control System

## Project Summary

This project demonstrates the implementation of secure Role-Based Access Control (RBAC) in Linux using users, groups, ownership, and file permissions.

The solution was designed for a company with multiple departments where employees must only access resources belonging to their assigned department.

## Business Scenario

A growing company has recently hired employees for:

- Information Technology (IT)
- Human Resources (HR)
- Finance
- Management

The company requires a secure file-sharing environment that:

- Allows collaboration within departments
- Prevents unauthorized access between departments
- Maintains administrative oversight
- Follows the principle of least privilege

## Objectives

- Create departmental groups
- Create employee accounts
- Implement access control
- Configure shared departmental directories
- Enforce security policies
- Test access restrictions
